## File Organizational Structure

1. We will use slugs! Scripts will be numbered 01, 02, 03, etc. and outputs will follow that convention.
2. No capital letters in file names or folder names
3. We like underscores for file names
4. More discretion can be used within a script for using caps, CamelCase, pascalCase, etc. for objects and variables
5. Our raw data will have some sort of file naming convention so we don't get lost in a sea of illegible file names
6. We will clear our environments before running and testing code! rm(list = ls()); gc()
